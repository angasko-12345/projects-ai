The tiny language model learns to predict the next token.
Given a sequence of tokens, it reads the past and guesses what comes next.
Training shows it many passages so it learns patterns of words and ideas.

A transformer block has two parts with skip connections that add the input back.
First, causal self-attention lets each position look at earlier positions.
Each token makes a query, a key, and a value: Q = xWq, K = xWk, V = xWv.
Attention scores are scaled dot products of queries and keys.
A causal mask hides future positions so no token can peek ahead.
Multiple heads run attention in parallel and their outputs are joined.
Second, a small feed-forward network with GELU processes each position alone.
Layer normalization steadies the values before attention and before the network.
Stacked blocks build richer meaning, then a final layer predicts the next token.
